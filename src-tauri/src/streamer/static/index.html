Switch to HTTPS: faster and more secure

This page is on an insecure (HTTP) connection. Your browser only unlocks the low-latency video and audio paths on a secure one, so switching makes the screen faster as well as private. You will see a one-time warning about the self-signed certificate; that is expected — choose Advanced (or More Info), then continue to the site.

Limited Browser Support

    You're on the device being controlled

    This browser is running on the same computer ScreenExtend is extending. To use it as a second screen, open this page on an additional device, like a phone, tablet, or another laptop.

    Allow microphone access

    To let the host choose where this device plays audio (a specific speaker, or the phone's earpiece), ScreenExtend needs brief microphone access to detect the available outputs. Your microphone is never recorded or streamed.
